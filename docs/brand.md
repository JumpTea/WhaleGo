# 品牌与宣传片

## 1. 名字

**鲸语 · WhaleGo**

- 鲸鱼靠声呐辨认方向，靠鲸歌交换消息。听与说，本来就是鲸鱼的事。
- `whale` 是 DeepSeek 的意象；`Go` 指 DSH-Go。
- 中文名取「鲸歌」与「语言」的双关：声音先到，文字随后。

一句话：**先听见，再见。**

英文：**Hear it first. Read it after.**

## 2. 像素鲸

`assets/brand/`：

| 文件 | 用途 |
| --- | --- |
| `pixel-whale-1024.png` | 主图，深色圆角底 |
| `pixel-whale-512.png` | 应用图标、头像 |
| `pixel-whale-256.png` | 列表、面板 |
| `pixel-whale-128.png` | favicon、小尺寸 |
| `pixel-whale-mark-1024.png` | 透明底，叠在任意深色背景 |
| `social-preview-1280x640.png` | GitHub social preview、宣传图 |

生成脚本：`tools/brand/make-brand.py`。64×64 网格，最近邻放大，边缘保持硬像素。

造型要点：

- 圆润的侧身鲸：大尾鳍、单眼、浅蓝腹，轮廓先读成鲸，再读成角色。
- 头顶一根深色小杆，顶端 2×2 青色声呐球，两侧各一粒涟漪；这是角色的独有剪影。
- 青色脸颊，替代常见的粉色腮红；全图只保留这一处暖色以外的强调。
- 深墨蓝圆角底，青色是唯一强调色；不描长条鱼、不做通用鲸鱼贴纸。
- 造型为原创：不使用现成吉祥物的轮廓、配色、腮红或表情，声呐天线与青色脸颊是本项目自己的识别点。

使用规则：

- 深色底为主；浅色底只在文档里用，且保持同一组色。
- 青色只做强调，不大面积铺底。
- 不用紫色渐变、不用玻璃拟态、不用无意义的发光。

## 4. 标识使用

- 最小尺寸：24 px；小于 24 px 只用透明底鲸鱼，不加圆角底。
- 留白：标识四周至少留 1/4 个标识宽度的空白。
- 不拉伸、不旋转、不改色、不加投影、不重绘像素。
- 不把鲸鱼和文字拆开单独授权；组合标识以 `social-preview` 为准。
- 可以在「关于」「宣传片」「README」里使用；不得用于暗示 DSH-Go 官方背书。

## 6. 宣传片

### 6.1 规格

- 时长：75 秒
- 画幅：1920×1080，30 fps
- 编码：H.264 High，yuv420p，AAC 192 kbps
- 响度：-14 LUFS（平台标准），峰值 ≤ -1 dBTP
- 语言：中文旁白；屏幕文字中英双语只在标题与结尾出现
- 素材：像素鲸、Pillow 合成 UI 与声呐环、ACE-Step 配乐、Edge TTS 旁白与演示声

### 6.2 分镜

| 时间 | 画面 | 旁白 | 屏幕文字 |
| --- | --- | --- | --- |
| 0–5s | 深墨蓝底，同心声呐环扩散；像素鲸从右下游入并停住 | 有些问题，一句话说不清。 | 鲸语 · WhaleGo |
| 5–13s | 左右分屏：左边「只说」浅波形，右边「只写」慢文字墙；中间裂开 | 说得快，往往说得浅；写得好，又来得太慢。 | 只说 / 只写 |

### 6.3 旁白

用 Edge TTS `zh-CN-XiaoxiaoNeural`，rate `-5%`，逐句生成，句间留 0.3–0.6 秒。旁白不是朗读说明书，语气要像在讲一个发现。

```text
有些问题，一句话说不清。
说得快，往往说得浅；写得好，又来得太慢。
鲸语让两个脑子同时工作。一个先说，一个后写。
语音在会话里生长，文字答案紧随其下。
它不等你听完，也不打断你说话。
悬浮球、声音、设置，都交给原生。
鲸鱼用声呐辨认方向，用鲸歌交换消息。
Whale 是 DeepSeek 的意象，Go 是 DSH-Go。
先听见，再见。
鲸语 WhaleGo，MIT 开源。
```

演示段里的「我想想。」「行，我来查查。」用 `zh-CN-YunxiNeural` 生成，和旁白区分开；它们是产品声音，不是旁白。

### 6.4 配乐

ACE-Step，英文 caption：

```text
ambient sonar, soft synth pulse, warm pad, minimal, 75 bpm, no vocals, instrumental
```

生成 90 秒，取前 75 秒；旁白下自动 duck 到 -18 dB，句间回到 -12 dB。结尾 2 秒淡出。

### 6.5 视觉

- 背景：深墨蓝网格 + 程序化同心声呐环；不使用 Wan 生成背景，避免素材风格与像素鲸打架。
- UI：用 Pillow 画手机框、会话与设置面板，严格使用第 3 节色板；表格数据标「示例数据」，不冒充真实榜单。
- 动效：声呐环用同心圆 + 透明度衰减；文字逐字出现用固定步长，不用弹簧；转场只用切和短叠化。
- 像素：所有鲸鱼、图标、边框按 64px 设计网格对齐；放大用最近邻，不糊边。

### 6.6 合成

1. 逐帧渲染 1920×1080 PNG（2250 帧），或按镜头渲染再拼接。
2. ffmpeg 合成：`-r 30 -c:v libx264 -preset slow -crf 18 -pix_fmt yuv420p`。
3. 音频：旁白 + 演示声 + BGM，`loudnorm=I=-14:TP=-1:LRA=11`。
4. 输出 `assets/promo/whalego-promo-75s.mp4`，另出 1280×720 压缩版。
5. 抽 6 帧检查：标题、双脑、复杂演示、悬浮球、品牌、结尾；确认无错字、无个人信息、无真实通知。

### 6.7 隐私门禁

- 不出现真名、手机号、邮箱、社交账号、真实头像、真实聊天记录。
- 不出现手机状态栏的真实运营商、通知、电量以外的个人信息；演示 UI 用合成状态栏。
- 不出现跳转到个人信息页面的二维码或链接；只放仓库地址。
- 素材文件名、EXIF、字幕文件都不带作者信息。
- 发布前跑一次仓库级 `grep` 与视频抽帧目检。

> 鲸语 WhaleGo：DSH-Go 的双脑语音插件。语音先说，文字后写；无字幕，无弹幕，悬浮球与设置都交给原生。

> 有些问题一句话说不清。鲸语把回答拆成两条通道：语音脑先开口，把转写流进会话；文字脑同时工作，把完整答案写在下面。语音继续增长时，文字答案被自然往下推。悬浮球、声音、设置全部由 DSH-Go 原生绘制，插件只声明。MIT 开源。
