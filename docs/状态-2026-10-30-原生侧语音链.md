## 结论快照

1. **两条旧结论复查**（读上游参考源证据）：island WebView 权限仍 `deny()`、NativeMediaPlugin
   只发 `voice.speechStart/End`（无 partial/final 文本）→「App 内 WebUI 拿不到麦克风」成立；
   「原生 UI 侧实现不了插件目标」收窄：语音行持久化/渲染/内联播放已由 App 原生实现（durable rows
   三连提交），插件侧目标可以用「消息级路径」达成，不再依赖 voiceLine 桥。
2. **原生侧复刻**（hostWrites lane）：`session/event → onUserMessage → onSessionMessage →
   #runVoiceRows`。用户消息自动补 A 段语音行（不自动播放，强调内联重播）；B 段由宿主 agent 自己
   的回合承担，不再双写。`#ownPrompt` 印记防自触发。
3. **提醒**：鲸语按钮 toast+复制入口地址（12h 节流，hintAt）、live 面板提示行与「浏览器入口」按钮、
   设置页 `nativeAuto` 开关。
4. **dsh-go 新版**：npm rc.5 宿主已升级并冒烟；App 0.9.4 事实与适配边界见专题 §2/§7。
5. **版本**：`0.9.0`（package.json + CLIENT_BUILD 同步）。

> 逆向事实与吸收/共生/不搬三档方案见 [`专题-逆向dsh-orb与融合.md`](专题-逆向dsh-orb与融合.md)

### 落地（0.9.1）

1. **吸收三段语音命令**（纯 JS 零新依赖，`voiceCommands='off'` 默认全旁路）：
   `voiceCommand()` matcher——wake 前缀匹配（正文提到唤醒词不算命令，同 dsh-orb `stripWakePrefix`；
   wake 判定在 break 之前，防默认 breakPhrase「小鲸」吞掉唤醒词）、break/stop 关键词全帧匹配（同
   dsh-orb interject/dismiss，空短语不匹配）；`voiceCommandsOff()` 是总旁路道岔，挂在 onresult 的
   echo 过滤之后（TTS 自声进不来）。break→打断转听+回喊；stop→停播关麦收起；wake 尾问 ≥4 字走
   分帧 pending 通道（播报中也生效）。
2. **prefs 四短语**：`wakePhrase`（你好小鲸）/ `breakPhrase`（小鲸）/ `stopPhrase`（退下吧）/
   `wakeReply`（我在呢。）+ 总开关 `voiceCommands`；normalize/patch 钳制（≤40/80 字、trim、空值回退默认）；
   设置页「语音命令」区块（预设枚举选项）。
3. **共生探测 `lib/orbBridge.js`**（只读）：认 profile `orb-*.json` / `ball-enabled.json`（profiles/* 一层扫描）
   与 `~/.dsh/dsh-orb` 的 runtime/voice 目录；voice schema 钳制同构 dsh-orb 自己的 `text()` / `numberIn()`
   惯例（非字符串才回退、0.05–0.9 / 500–5000 区间钳制）；诊断 rows 追加 dsh-orb 行 + `companion` 字段。
   宿主装了 dsh-orb 时 13 个 GUI 工具本就随其 cordis patch 注入会话（同宿主免费获得，不搬实现）。
4. **不搬**：Electron helper 球窗、koffi FFI、sherpa-onnx 本地模型等 149MB 原生依赖（违反「不引入运行时依赖」）。
