## 结论快照

1. **两条旧结论复查**（读 dsh-go-src 证据）：island WebView 权限仍 `deny()`、NativeMediaPlugin
   只发 `voice.speechStart/End`（无 partial/final 文本）→「App 内 WebUI 拿不到麦克风」成立；
   「原生 UI 侧实现不了插件目标」收窄：语音行持久化/渲染/内联播放已由 App 原生实现（durable rows
   三连提交），插件侧目标可以用「消息级路径」达成，不再依赖 voiceLine 桥。
2. **原生侧复刻**（hostWrites lane）：`session/event → onUserMessage → onSessionMessage →
   #runVoiceRows`。用户消息自动补 A 段语音行（不自动播放，强调内联重播）；B 段由宿主 agent 自己
   的回合承担，不再双写。`#ownPrompt` 印记防自触发。
3. **提醒**：鲸语按钮 toast+复制入口地址（12h 节流，hintAt）、live 面板提示行与「浏览器入口」按钮、
   设置页 `nativeAuto` 开关。
4. **dsh-go 新版**：npm rc.5 宿主已升级并冒烟；App 0.9.4 事实与适配边界见专题 §2/§7。
5. **版本**：`0.9.0`（package.json + CLIENT_BUILD 同步）。
